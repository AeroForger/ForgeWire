# ForgeWire

>[!WARNING]
>This project is at really early stage of development

## Purpose

ForgeWire a simple Cli too that helps you talk without talking in real life

## how it works

User inputs text which get converted to bytes and then bytes are sent to a Virtual mic that is created by the program

## current state - still developing

Right now i'm planning to add:

- Pulse audio support

- TTS settings

- Better pipewire support
